# 目标与约束

## 学习者背景（公开版）

- 会 C++ 和基础 Python；看过 nanoGPT；还没有 AI Infra 项目、实习或工程经验。
- 目标：进入 AI Infra 方向（推理引擎 / 训练框架 / 算子 / 平台）。
- 学习节奏：考试前每天最多 30 分钟；考试后集中推进；之后可用本机 GPU 做 CUDA。
- 个人背景、学校、考试等细节只保存在本地私有文件，不上传 GitHub。

## 这个项目要解决什么

用尽量少的文档和尽量多的代码，从零实现并理解：

1. 二维 Tensor、算子与自动求导；
2. 单头、单 Block 的小 GPT，真实文本训练与逐字符生成；
3. CPU 上的性能实验（分块、OpenMP、SIMD、Roofline），理解 GPU 执行模型；
4. 用本机 GPU 写 CUDA 算子（matmul、softmax、LayerNorm、attention）；
5. 后续的 mini 推理引擎（KV Cache、连续批处理、量化）作为求职主项目。

## 边界（不做什么）

- 不做多卡、分布式训练、完整 PyTorch 兼容、生产服务。
- 不把文档、教学网页、版本路线当成主要工作；代码和真实数字优先。
- **本版本不维护教学网页**；讲解只放在 `docs/` 与对话里。
- 不追求“一次设计完美”，每步只解决一个小问题。

## 成功标准

- 每个步骤都有可运行的测试或 benchmark 数字；
- 能向别人解释：代码在算什么、shape 为什么这样、性能数字怎么来的；
- 考试后 3～4 个月内完成 M1～M3；CUDA 在本机 GPU 上跑通关键算子；
- 简历上能写出“C++ 手写 GPT + 性能优化 + CUDA 算子”的可验证项目。
